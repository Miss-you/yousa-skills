# KOSPI Monitor 桌面页面设计

## 适用范围与依赖

设计或修改 KOSPI Monitor 的 `public/` Dashboard、独立专题页与 `src/reporter/` 桌面 HTML 时使用。先在 **kospi-monitor 仓库根目录**阅读 `AGENTS.md` §7 和 `docs/reference/dashboard-design-system.md`；本 skill 补充排版与字体决策，强制的颜色语义、数据与交互契约以项目规范为准。下文的相对文件路径也都以该仓库根目录为准。手机布局另见 `$kospi-mobile-web-design`。

## 工作步骤

1. 确认面板要回答的问题、数据状态、日期、来源和单位；按项目规范核对图表和检查器契约。
2. 按下述信息层级布置页面，再依据字体与宽度基线调整列数、留白和换行。
3. 用真实数据及 `STALE`、估算、`N/A` 状态验收布局、精确值读取和键盘操作。

## 信息层级

保持高密度、低噪声的运行监控气质。顶部放品牌、少量全局筛选与入口；其下依次给出数据状态、当日资金与价格、历史趋势、精确检查器和明细。新面板回答一个主要问题，状态、日期、来源和单位靠近数值展示。`STALE`、估算、`N/A` 不得被图形或颜色掩盖。

## 字体与宽度

| 内容               | 桌面基线                                       |
| ------------------ | ---------------------------------------------- |
| 页面 / 区域标题    | 约 20–26 px；已有 Dashboard 品牌栏可保持 17 px |
| 面板标题           | 16–18 px                                       |
| 正文与精确数值     | 13–16 px，重点数值可按报告语境放大             |
| 元数据、图例与表头 | 通常 11–12 px；避免把关键状态压进更小字号      |

系统无衬线负责标题与标签，系统等宽负责 ticker、时间和精确值。字号由阅读优先级决定；面板放不下时先调整列数、留白或文本换行。颜色使用 `public/style.css` 的 `:root` token，间距沿用 8 / 12 / 16 px，圆角 4–6 px、细边框。

主 Dashboard 容器默认最大 1760 px。宽度超过 1180 px 时，当日面板最多两列；历史图、外资持股率和个股回购各占整行。761–1180 px 将当日面板改为单列。图表下始终保留常驻精确值检查器，不能仅靠 hover 读数。

## 验收

在 1440 × 1200 和约 1180 px 宽度检查标题、单位、状态、图表、检查器与表格；无碰撞、裁切和无意义空白。检查浏览器缩放后数值仍能读、键盘可定位图表观测点。前端改动还需遵守 `AGENTS.md` §7.8 的完整验收门槛。

## 应用示例

新增外资持股率面板时，把标的、市场日、单位和状态放在面板头；趋势图独占整行，图下常驻显示所选真实交易日的精确百分比，明细表可展开。遇到 `null` 时断线并显示 `N/A`，不把它绘成零或沿用前值。

## 常见错误

- 为塞进更多卡片恢复三列窄布局，或把关键状态缩成难读的小字。
- 只在 hover tooltip 中提供精确值，使键盘和触控用户无法读取。
- 用颜色或图形掩盖 `STALE`、估算和缺失状态，或把不同单位画在同一比例尺上。
