# 整理与核验个人音乐库

交付真实可播放的文件，以及足以追溯曲名、切点和标签的证据。曲目身份、版本完整性、切分正确性、音质与作者署名分别验收；其中一项通过不能替代其余项。

## 个人偏好与范围

- 封面默认由用户提供。缺图时简短索取，继续其他工作；除非用户另有要求，不自行搜图、生成或裁切替代封面。
- 根据本轮请求选择入口：完整整理走全流程；只改封面或标签时，保留现有正确信息，跳过下载和切分。已授权的本地可逆处理直接推进。
- 根据已有上下文确定目标曲目、播放格式和输出位置。缺少决定性输入才提问；不要重复询问已给过的偏好。实际源文件缺失时先寻找可获得的对应资源。
- 默认保留原始源和旧成果。当前交付置于单独目录，清楚标识旧版，验收后再替换当前压缩包；不擅自删除或发布文件。

## 1. 清点源文件与查找资源

先用 ffprobe 或等效工具实测音轨、时长、编码、采样率、声道、现有标签，记录来源 URL／文件哈希及取得日期。视频描述和时间轴只是候选线索；发现总时长、首曲或曲数不符，先查缺曲、版本和编辑差异。

按需联网查官方完整单曲／专辑、合法可获取的音源、作者原始发布，再考虑可追溯的第三方参考。会员离线缓存不等于可导出文件。更高质量版本需对应同一录音；翻奏、重制和不同剪辑不能悄悄替换原版。不绕过访问控制或 DRM。

质量判断分清：源真实性、编码参数、可检测缺陷、听感。FLAC 扩展名、高码率或高采样率都不单独证明无损或更好；有损转 FLAC 不恢复细节。只在取得充分依据时升级源。搜不到时记录检索范围与日期，表述为“未找到可验证来源”。

## 2. 建立曲名与声音的对应

官方曲目表用于核对规范名称；用音频内容建立“本地片段 → 参考录音 → 曲名”的证据链。不要把官方排序、评论排序或文件名当成混编顺序，也不要在证明身份前按这些顺序重命名。

从每个参考的前、中、后取具有辨识度的非静音窗口，先在整段音源定位；必要时加密检查全曲及异常点。至少设置错曲、相似主题／循环或同曲另一版本的对照。正例分数高但错例同样高时仍属歧义；相关性分数不是概率。

检查参考是否转引同一个上游。不同上传账号并不保证证据独立。分别记录“曲名有官方依据”“音频匹配第三方参考”“比对官方录音”的证据等级。

## 3. 提出切点、找反例、再切分

开始切分前读取 [references/verification.md](references/verification.md)，先写简短验收计划与候选曲目表。

综合内容变化、参考首尾、波形／频谱、不同阈值下的低电平区间定位边界。阈值按素材调整；曲中休止、低音量弦乐、渐弱尾音都可能是假边界，不存在通用的静音阈值。

给出可接受的边界区间及选择理由，不虚构唯一正确毫秒。干净间隔可选中部留余量，并检查实际输出切点。相邻曲目默认连续分配源区间；任何删去或重复内容都要说明。

交叉淡化、叠音、缺头缺尾不能靠硬切恢复完整独立录音：找完整单曲替换或标明摘录限制。遇到影响目标的取舍，只问该处并继续不受影响的曲目；不通过淡出掩盖缺失。

## 4. 导出、封面与标签

播放器支持时优先保留原编码；需要兼容格式才从最佳原始源编码一次，避免串联转码。不要把 Opus 固定成所有源的默认格式；AAC 源可直接封装为 M4A。若用户没有既定格式，可交付保留原编码版和 MP3 兼容版，并说明后者是否增加有损转换。

写入前读取 [references/metadata.md](references/metadata.md)。逐项保留来源与置信状态；个人曲库分类可自行合理设置并说明，个人作曲／演奏署名必须有对应证据。封面按用户原图嵌入每首文件，不能只放一个 cover.png 就称已嵌入。

## 5. 验收与交付

仅修改标签或封面时，验收限于本轮字段、原有标签保留、图片、编码音频负载不变及交付包一致性。没有新异常时，不重复曲目映射、切点、整曲解码或试听；播放器可用时抽检显示，否则注明未测。以下完整音频验收用于新增切分、转码或修复。

逐文件检查：完整解码、实际时长／头尾、映射与切点、格式及标签读回、封面，以及目标播放器兼容性（具备条件时）。标签改动比较编码音频负载哈希；完整文件哈希变化是正常的。切片包一致仍须检查解码边界，详见验证参考。

把状态分开记录为：通过／有条件通过／待核实／失败。没有试听能力或未实际播放时明确“完成数值与文件校验，听觉验收未做”；不要写“已听过”“音质提升已确认”。身份或完整性失败的曲目不能混入无条件通过的成品。

推荐交付结构（按规模简化，不强制生成空文件）：

```text
output/<format>/01 曲名.<ext>
output/<format>/cover.png        # 用户提供时可附原图
audit/tracks.json                # 来源、映射、区间、标签依据、验收状态
audit/report.md                 # 结论、反例、未解决点及复现步骤
<collection>-<format>.zip
```

压缩包重建后检查成员数量、CRC 与成员字节是否匹配最终文件；旧包不能冒充最新结果。交付回答给绝对路径链接、曲数与格式、真实完成项和剩余限制。文件夹链接始终可找到，不只给技术报告。
