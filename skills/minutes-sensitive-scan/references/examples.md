# 案例对照表（提炼自一次真实的机构方两轮审稿 + 对抗复查；人物、机构、数字均已虚构化等效替换）

## 关于本样例的适用范围

本 skill 只做**对外发布前的脱敏**（不做纪要生成——那是姐妹 skill `transcript-to-deep-minutes` 的职责）。下方所有案例来自**一次金融闭门圆桌的真实两轮审稿 + 对抗复查**（人名、机构、数字已虚构化等效替换）。之所以完整保留这一个单一场景样例、而不是拆散做行业中性化，是因为**真实审稿链路上的信息密度**——哪些是机构方一定要删的、哪些可以改写、哪些是对抗复查才揪出来的——比虚构模板的教学价值高得多。

**跨场景使用时的映射方法**：

| 样例里的表达 | 换成你场景的等价物 |
|---|---|
| 百亿基金总裁 / 掌门人 / 一把手 | 科技公司 CEO / 开源社区核心维护者 / 主任医师 / 大学教授 / 你行业里的高段位角色 |
| 亚洲头部对冲基金某高管 | `[你的行业]+[段位]+[角色]` 结构套用 |
| "AI 没法去坐牢，人要去坐牢" → 受监管行业合规句式 | 换成你行业的合规/规范/风控措辞 |
| "只能用某指定办公软件、七成做 X 业务" | 你场景里的等价"专用工具 + 业务占比"指纹组合 |
| "远峰资本 / Alex Zhang / 张老师" | 你场景里的具体人名/机构名及变体（经 `--names` 传入脚本） |

**不变的是九类风险的结构与处理手法**：直接身份 / 职级暗示 / 玩笑话与人事信号 / 点评同行 / 口语化敏感词 / 结构性风险 / 外链击穿 / 指纹拼图 / 第三方未公开信息与隐私，加上"编辑残留"。**原案例照抄行不通，照结构套用一定能覆盖你的场景**。

---

按九类风险组织。"机构方意见"标注 = 被脱敏方明确提出的修改要求，代表机构视角的真实底线。示例中的人名/机构/数字全部虚构，但每条的**风险模式与修复手法**与真实案例一一对应。

## 1. 直接身份与职级（机构方意见，整改两轮）

| Before（虚构示例） | After |
|--------|-------|
| 远峰资本总裁张老师 / Alex Zhang | 某行业头部机构的一位高管（下称「嘉宾」） |
| 当百亿基金总裁坐进鱼缸（标题） | XX 主题：闭门圆桌讨论摘要 |
| 掌门人 / 一把手 | 某行业头部机构高管 |
| 主持人 Lina | 主持人（整理者署名处可保留真名——查塔姆规则约束发言归属，不约束整理者署名） |

要点：查塔姆规则下**嘉宾本人同样匿名**；身份模板 = 行业 + 段位 + 角色，不到机构名（如"亚洲头部对冲基金某高管"句式——按本次场景替换行业词）。第三方公众人物（公开报道中的 CEO 等）的职级词可保留。

## 2. 玩笑话与人事信号（机构方意见：整句删除，不要改写）

- 删：「给每人配个工牌录音，谁划水我都知道」类监控玩笑及配套的"圆形监狱"式评述——机构方原话"不建议当做玩笑～"
- 删：「省下来的人头编制先不补了哈」类编制信号全部出现处——机构方原话"会给别人感觉 AI 提效=不需要补充人手"；连衍生表述（"这决定了编制决策的颗粒度"）一并改写
- 经验：玩笑话的风险不在内容而在**回流路径**——纪要会传回说话人自己的组织；改写仍留痕迹，必须整句删除

## 3. 点评同行（机构方意见）

- 删：「同行 X 类业务出海至今没有一家跑通」式论断 + 据此立论的段落 + 配套的指向某具体同行亏损数据的媒体引用
- 要点：泛论 + 指向具体公司的引用 = 把泛论钉到具体同行头上；**引用比论断更危险**，必删

## 4. 口语化敏感词对照表（机构方意见；此表为通用词替换，可直接套用）

| Before | After |
|--------|-------|
| AI 没法去坐牢，人要去坐牢 | 在受监管行业，AI 可以辅助分析和流程执行，但关键判断、审批和责任归属必须由有资格的人来承担（机构方提供的标准句式，可直接复用） |
| 领先监管不是优势，是裸奔 | 跑在监管前面不是优势，而是缺乏保护的合规风险 |

| 翻墙+外卡 | 网络与支付门槛 |

| 死穴 | 痛点 |

## 5. 结构性风险（机构方意见）

- 「TOP N 金句」独立章节整体删除——引语内容若已存在于议题正文，删章节零信息损失，只去掉"语录传播"的形态；「实践故事集」→「实践案例参考」；戏剧化案例标题改描述性（"被泼了盆冷水"→"目标用户悖论"）
- 机构方原话："这个结构会天然放大大家的八卦心态"

## 6. 外链击穿匿名（对抗复查发现）

- 正文匿名"某车企创始人"，但附的新闻链接点开即实名 → 删链接改"据公开报道"；若该言论本为公开发言，也可正文直接实名（公开发言不受查塔姆规则约束）
- 规则：每条外链问一句——**"点开后读者多知道了谁？"**

## 7. 指纹拼图（对抗复查发现：单条无害、叠加锁定唯一）

虚构示例组合："平台式机构 + 网上几乎搜不到 + 约 N 十个团队 + 七成做某类业务 + 只能用某指定办公软件 + 人员高速增长"——该画像在候选集里可能只剩个位数机构。

| Before | After |
|--------|-------|
| 约 60 个团队、七成做 X | 大量团队、以 X 为主 |
| 网上几乎搜不到，直到招聘才曝光 | 市场形象极为低调（独特叙事直接删除） |
| 只能用某指定办公软件 | 只能用合规审批过的少数协同工具 |
| 依据 X 年 X 月 X 日转录（精确日期可反查参会名单） | 依据 X 年 X 月闭门转录 |

## 8. 第三方未公开信息与个人隐私（对抗复查发现）

| Before | After |
|--------|-------|
| 某平台 BD 团队已内测"录音+AI 写报告" | 据参与者转述，已有团队在试点（"内测中"是别家未发布信息） |
| 定价 X 元/周、周回购 X% | 订阅制、回购率健康（精确商业数字可反查产品） |
| 团队从 40 人裁到 15 人 | 团队规模正在主动精简（裁员计划属未公开组织信息） |
| 长期失眠靠药物 / 住进 ICU | 健康透支 / 因健康问题入院（**个人健康与私生活细节一律模糊化**） |

## 9. 编辑残留（对抗复查发现）

- 「除嘉宾与主持人 外」——删名后的异常空格，向读者暗示此处原有名字
- 「整理：终稿撰写人」——流水线占位符未替换
- 规则：删替换操作后，grep 中文间异常空格 / 占位符词（终稿撰写人、TODO、XXX）/ 精确日期

## 10. 带核查的整理稿：特有的击穿路径（人物、机构、行业均为等效示例）

这类稿子先复述嘉宾讲了什么，再逐条核查，后面挂几十条脚注。正文匿名做得再干净，下面几条路径照样能把人认出来。

| Before（等效示例） | 为什么能反查 | After |
|--------|-------|-------|
| 正文三处分别写“嘉宾与所讲行业有利益关联”“他也承认，少用外包这条建议对他自己的生意不利”“最后一条甚至不合他自己的利益” | 三句叠起来，读者推出他的生意靠别人用外包，再叠加讲的是哪个行业、哪个地区，候选只剩一到三家公司 | 利益关联只在开头写一次固定句式；正文写“没有一条明显偏向他自身利益的立场”，不露业务类型 |
| “一家欧洲连锁零售商的高管当面说，明年要关掉三成门店” | 和某位高管的公开表态高度吻合，读者第一个猜的就是它；还把一个与公开记录不符的“三成”安到了对方头上 | “已有零售企业的高管讲，线下门店会大幅收缩” |
| “他转述某国一家航空公司的说法：本来以为要倒闭了” | 那个国家的大航司里，只有一家有过濒临破产、靠政府救助的历史 | “他转述航空业内人士的说法：前些年以为撑不下去了” |
| “有一家媒体还撤过一篇讲某车企库存积压的稿子，标题也改了” | 公司加话题加改标题，只对得上一篇报道，“集体唱衰”的指控落到唯一一家媒体头上 | “他说有的报道甚至撤过稿、改过标题” |
| 正文写“有一家咨询公司从中牵线”，脚注链接的网址里就写着那家公司的名字 | 正文匿名、链接实名，指控被钉到具体机构 | 删掉指控那半句；核查段落里“被点到的那家”改成“几家头部咨询公司” |
| “某公司在分享会前一天下午已经公告”“比分享会前一个交易日涨了 X%” | 公告日、交易日都公开可查，等于写出了活动日期和时段，可以反查当天到场的人 | “在分享会之前也已经公告”“比上月末收盘”（换成与活动日期无关的公开基准） |
| 脚注里写“明细见核查存档 F02” | 内部流水线代号，读者打不开，还暴露有一套内部底稿 | 换成公开出处的链接 |

还有一条流程上的教训：这份稿子在脱敏之后又按保真验收的意见补了几句，第一条风险正是补进去的那句造成的。**验收后改过的句子，要对改动处重跑脱敏。**
