## 2. 玩笑话与人事信号（机构方意见：整句删除，不要改写）

- 删：「给每人配个工牌录音，谁划水我都知道」类监控玩笑及配套的"圆形监狱"式评述——机构方原话"不建议当做玩笑～"
- 删：「省下来的人头编制先不补了哈」类编制信号全部出现处——机构方原话"会给别人感觉 AI 提效=不需要补充人手"；连衍生表述（"这决定了编制决策的颗粒度"）一并改写
- 经验：玩笑话的风险不在内容而在**回流路径**——纪要会传回说话人自己的组织；改写仍留痕迹，必须整句删除

## 3. 点评同行（机构方意见）

- 删：「同行 X 类业务出海至今没有一家跑通」式论断 + 据此立论的段落 + 配套的指向某具体同行亏损数据的媒体引用
- 要点：泛论 + 指向具体公司的引用 = 把泛论钉到具体同行头上；**引用比论断更危险**，必删

## 5. 结构性风险（机构方意见）

- 「TOP N 金句」独立章节整体删除——引语内容若已存在于议题正文，删章节零信息损失，只去掉"语录传播"的形态；「实践故事集」→「实践案例参考」；戏剧化案例标题改描述性（"被泼了盆冷水"→"目标用户悖论"）
- 机构方原话："这个结构会天然放大大家的八卦心态"

## 6. 外链击穿匿名（对抗复查发现）

- 正文匿名"某车企创始人"，但附的新闻链接点开即实名 → 删链接改"据公开报道"；若该言论本为公开发言，也可正文直接实名（公开发言不受查塔姆规则约束）
- 规则：每条外链问一句——**"点开后读者多知道了谁？"**

## 7. 指纹拼图（对抗复查发现：单条无害、叠加锁定唯一）

虚构示例组合："平台式机构 + 网上几乎搜不到 + 约 N 十个团队 + 七成做某类业务 + 只能用某指定办公软件 + 人员高速增长"——该画像在候选集里可能只剩个位数机构。

| Before | After |
|--------|-------|
| 约 60 个团队、七成做 X | 大量团队、以 X 为主 |
| 网上几乎搜不到，直到招聘才曝光 | 市场形象极为低调（独特叙事直接删除） |
| 只能用某指定办公软件 | 只能用合规审批过的少数协同工具 |
| 依据 X 年 X 月 X 日转录（精确日期可反查参会名单） | 依据 X 年 X 月闭门转录 |
